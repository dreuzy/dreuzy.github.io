HydroModPy

HydroModPy is an open-source Python toolbox for building, running, calibrating and analysing catchment-scale shallow-groundwater models in a reproducible way.

From catchment to model

The software brings catchment delineation, spatial and temporal data preparation, model definition, MODFLOW simulations, particle tracking and solute transport, and the export and visualisation of results into one workflow.

This shared pipeline makes assumptions explicit, facilitates comparisons between sites and makes computations reproducible. It supports both detailed catchment studies and ensembles of models deployed over larger regions.

Scientific uses

Shallow aquifers

Represent groundwater–stream exchanges and constrain hydraulic properties using observations available at catchment scale.

Multi-site comparison

Apply a consistent protocol to many catchments while preserving the traceability of data, parameters and results.

Multi-fidelity approaches

Combine fast models, regional ensembles and detailed process models according to the scientific question and available data.

Versions and reproducibility

HydroModPy v1.0 is the version documented in the 2026 reference paper. The v2 documentation describes the evolving architecture. Published documentation versions remain separately available so that a computation can be linked to the software environment in which it was produced.

The code, tests, examples and version history are public. Scientific work should report the package version and cite the reference paper.
